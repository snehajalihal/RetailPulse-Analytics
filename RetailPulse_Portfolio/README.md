# RetailPulse — Sales & Profitability Analysis

## Overview
RetailPulse is a retail business analytics project that explores sales, profitability, discount patterns, and regional performance using a sample retail dataset.

The project combines Microsoft Excel, MySQL, and Power BI to transform raw sales data into actionable business insights.

## Business Objectives
- Analyze sales and profit performance across product categories.
- Identify loss-making product subcategories.
- Compare regional profitability.
- Investigate the relationship between discounts and losses.
- Present insights through an interactive Power BI dashboard.

## Tools & Technologies
- Microsoft Excel
- MySQL
- Microsoft Power BI
- DAX

## Key Findings
- Total sales were approximately $2.30 million.
- Total profit was approximately $286,398.
- Technology generated the highest profit among the three product categories.
- Tables recorded the largest loss among the analyzed subcategories.
- The West region achieved the highest profit margin, while Central recorded the lowest.
- Transactions with discounts of 30% or more had a high loss rate.

## Recommendations
- Review high-discount transactions and their profitability.
- Investigate pricing and costs for loss-making subcategories.
- Examine regional differences to identify improvement opportunities.
- Monitor sales and profit trends through the Power BI dashboard.

## Project Structure
- `01_Dataset/` — Source dataset
- `02_SQL/` — SQL analysis scripts
- `03_PowerBI/` — Power BI dashboard
- `04_Documentation/` — Business insights report

## Disclaimer
This project uses a sample retail dataset for educational and portfolio purposes. Findings describe patterns in the dataset and should not be interpreted as proof of causation.
